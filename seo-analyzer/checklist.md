# SEO Checklist

## On-Page SEO

### Title Tag
- [ ] Present on every page
- [ ] 50-60 characters
- [ ] Unique across site
- [ ] Primary keyword included
- [ ] Compelling for clicks

### Meta Description
- [ ] Present on every page
- [ ] 150-160 characters
- [ ] Unique across site
- [ ] Contains target keyword
- [ ] Includes call-to-action

### Headings
- [ ] Single H1 per page
- [ ] H1 contains primary keyword
- [ ] Logical H2-H6 hierarchy
- [ ] No skipped heading levels
- [ ] Headings describe content sections

### Content
- [ ] Minimum 300 words for main pages
- [ ] Keyword density 1-2%
- [ ] LSI keywords included
- [ ] Readable (Flesch score > 60)
- [ ] No duplicate content

### Images
- [ ] All images have alt text
- [ ] Alt text is descriptive
- [ ] File names are descriptive
- [ ] Images compressed/optimized
- [ ] Lazy loading implemented
- [ ] WebP format used

### URLs
- [ ] Descriptive slugs
- [ ] Lowercase only
- [ ] Hyphens as separators
- [ ] No special characters
- [ ] Under 75 characters

## Technical SEO

### Indexing
- [ ] robots.txt present and valid
- [ ] XML sitemap present
- [ ] Sitemap submitted to Search Console
- [ ] No unintended noindex tags
- [ ] Canonical URLs set correctly

### Performance
- [ ] Page load < 3 seconds
- [ ] LCP < 2.5 seconds
- [ ] FID < 100ms
- [ ] CLS < 0.1
- [ ] Images optimized
- [ ] CSS/JS minified
- [ ] Gzip/Brotli compression

### Mobile
- [ ] Viewport meta tag present
- [ ] Responsive design
- [ ] Touch targets > 48px
- [ ] No horizontal scroll
- [ ] Font size > 16px

### Security
- [ ] HTTPS enforced
- [ ] HSTS header set
- [ ] No mixed content
- [ ] Security headers present

### Crawlability
- [ ] No orphan pages
- [ ] Max 3 clicks to any page
- [ ] Internal linking structure
- [ ] Breadcrumbs implemented
- [ ] No broken links

## Structured Data

### Required
- [ ] Organization/LocalBusiness schema
- [ ] Breadcrumb schema
- [ ] Article schema (for blog posts)
- [ ] Product schema (for e-commerce)

### Validation
- [ ] No errors in Rich Results Test
- [ ] No warnings in Schema Validator
- [ ] JSON-LD format used

## Social & Sharing

### Open Graph
- [ ] og:title present
- [ ] og:description present
- [ ] og:image present (1200x630px)
- [ ] og:url present
- [ ] og:type present

### Twitter Cards
- [ ] twitter:card present
- [ ] twitter:title present
- [ ] twitter:description present
- [ ] twitter:image present

## International SEO

- [ ] hreflang tags (if multilingual)
- [ ] Language declared in HTML
- [ ] Proper URL structure for locales
- [ ] Content properly translated

## Analytics & Monitoring

- [ ] Google Analytics installed
- [ ] Google Search Console connected
- [ ] Core Web Vitals monitored
- [ ] 404 errors tracked
- [ ] Crawl errors monitored
